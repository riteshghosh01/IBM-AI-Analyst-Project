# 🍽️ Foodie — AI-Powered Restaurant Website & Chatbot

> A modern restaurant website integrated with an AI-powered chatbot using IBM watsonx Assistant.

🌐 **Live Demo:** https://riteshghosh01.github.io/IBM-AI-Analyst-Project/

## 📌 Overview

Foodie is a restaurant website that allows customers to explore the menu, check prices, find the restaurant location, learn about delivery options, and reserve tables. It also includes an **IBM watsonx Assistant chatbot** for quick and interactive customer support.

## 🎯 Objectives

- Provide 24/7 customer assistance
- Answer common restaurant queries
- Provide menu and price information
- Assist with table reservations
- Provide delivery and location details
- Reduce repetitive staff queries
- Improve customer experience

## 🤖 AI Chatbot

The chatbot is built using **IBM watsonx Assistant** and integrated through the **watsonx Web Chat Widget**.

It supports:
- 👋 Greeting
- 🍴 Menu
- 💰 Food Prices
- 🕐 Opening Hours
- 🪑 Table Reservation
- 🚚 Delivery
- 📍 Location
- 🎁 Offers

## 🔄 Chatbot Workflow

Customer → Foodie Website → Web Chat Widget → IBM watsonx Assistant → Intent & Entity Matching → Dialog Logic → Bot Response

The chatbot identifies the customer's request and provides the appropriate response.

## 🪑 Table Reservation

The chatbot uses a guided conversation to collect:

**Date → Time → Number of Guests → Confirmation**

This makes table booking simple and interactive.
